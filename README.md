## 📦 Instalasi (Cara Pasang)

Ikuti langkah-langkah ini perlahan untuk pemula:

### 1. Download Bot
Buka terminal (Command Prompt atau PowerShell) dan ketik perintah ini:

```bash
git clone https://github.com/sipaldrop/DidGridBot-Sipal.git
cd DidGridBot-Sipal
```

### 2. Install Aplikasi Pendukung
Masih di terminal, ketik perintah ini untuk menginstall semua kebutuhan bot:

```bash
npm install
```
*Tunggu sampai proses selesai. Mungkin butuh beberapa menit.*

## ⚙️ Konfigurasi (Pengaturan)

### 1. Buat File Akun (`accounts.json`)
Kamu perlu membuat file untuk menyimpan data akunmu.
1.  Cari file bernama `accounts_tmp.json` di folder bot.
2.  Ubah namanya menjadi `accounts.json` (atau buat file baru).
3.  Buka file tersebut dengan Notepad atau Text Editor.
4.  Isi data akunmu seperti format di bawah ini:

```json
[
    {
        "name": "Account 1",
        "privateKey": "YOUR_PRIVATE_KEY_HERE",
        "proxy": "http://user:pass@ip:port"
    }
]
```
> **Catatan:**
> - `name`: Nama identitas untuk akun ini (Bebas).
> - `privateKey`: Private key wallet Metamask kamu (Hati-hati jangan disebar!).
> - `proxy`: (Opsional) Jika pakai proxy, isi formatnya. Jika tidak, kosongkan stringnya `""`.

### 2. Pengaturan Umum (`config.json`)
File `config.json` sudah diatur otomatis. Kamu tidak perlu mengubah apa-apa kecuali ada instruksi khusus dari update SipalDrop.
